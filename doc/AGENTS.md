# doc

## Purpose
Sphinx documentation source for the HyperSpy user guide, developer guide, and API reference. Built with `sphinx-gallery` for auto-generated example pages. Published at Read the Docs.

## Key Files

| File | Description |
|------|-------------|
| `conf.py` | Sphinx configuration — extensions, theme, intersphinx targets |
| `index.rst` | Documentation root / table of contents |
| `Makefile` | `make html` / `make linkcheck` etc. |

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `user_guide/` | End-user tutorials: signals, axes, model fitting, MVA, I/O, visualization |
| `dev_guide/` | Contributor documentation: architecture, coding style, release process |
| `reference/` | Auto-generated API reference (rst stubs) |
| `auto_examples/` | sphinx-gallery output (generated — do not edit directly) |
| `_static/` | Static assets (CSS, images) |
| `_templates/` | Jinja2 template overrides |

## For AI Agents

### Working In This Directory

- **Do not edit `auto_examples/`** — it is generated by sphinx-gallery from `examples/` at build time.
- **Do not edit `doc/_build/`** — generated output.
- Source files are in `.rst`; use MyST markdown (`.md`) only if a file already uses it.
- When documenting a new public API, add an entry to the appropriate `reference/` stub.
- Code examples in docstrings use ALL-DIFFERENT array dimensions to make axis reversals visible.

### Build

```bash
cd doc
make html          # full build
make linkcheck     # verify external links
```

### Testing Requirements

Doctest examples in `.rst` files are run as part of CI. Keep examples self-contained and importable.

### Common Patterns

- Intersphinx links to NumPy, SciPy, matplotlib, dask — check `conf.py` for configured inventories.
- Use `.. versionadded::` / `.. deprecated::` directives for API changes.
- New user-guide pages should be linked from `user_guide/index.rst`.

## Dependencies

### External
- `sphinx`, `sphinx-gallery`, `pydata-sphinx-theme`, `numpydoc`
