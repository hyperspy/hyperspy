Markers
=======

Gallery of examples demonstrating HyperSpy markers for enhancing visualizations.

Markers are visual annotations that can be added to plots to highlight features,
indicate positions, or provide additional information. This collection shows
how to use various marker types including:

- **Basic Shapes**: Circles, rectangles, ellipses, polygons
- **Directional Indicators**: Arrows, lines, vertical lines  
- **Text Annotations**: Text labels and annotations
- **Advanced Features**: Color coding, size variations, transformations
- **Interactive Elements**: Navigation-aware markers, dynamic updates

These examples demonstrate how markers integrate with HyperSpy's plotting
system to create informative and publication-ready visualizations.
