Multidimensional Visualization
==============================

Examples demonstrating visualization techniques for multidimensional datasets
in HyperSpy, including:

- **Navigator and Signal Plots**: Interactive navigation through datasets
- **Spectrum Images**: Visualizing hyperspectral data
- **Image Stacks**: Time series and multi-frame data visualization
- **ROI and Insets**: Region of interest visualization and inset creation
- **Interactive Features**: Dynamic navigation and position tracking

These examples show how to effectively visualize and navigate complex
multidimensional scientific datasets.
