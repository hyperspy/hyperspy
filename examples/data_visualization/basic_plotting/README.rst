Basic Plotting
==============

Examples demonstrating fundamental plotting techniques and customizations
in HyperSpy, including:

- **Custom Figure Layouts**: Composing complex figures with subfigures
- **Plot Customization**: Specifying axes, styling, and appearance
- **Figure Composition**: Combining multiple plots and visualizations

These examples focus on the core plotting capabilities and how to create
well-structured, publication-ready figures.
