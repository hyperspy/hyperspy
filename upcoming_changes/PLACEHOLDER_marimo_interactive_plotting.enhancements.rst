Add support for interactive plotting in marimo notebooks using :func:`marimo.mpl.interactive`. When running in a marimo notebook, :meth:`~.signal.BaseSignal.plot` now automatically uses marimo's interactive matplotlib viewer for pan, zoom, and coordinate display, replacing the ipympl-based approach. The ``plot_style`` preference (horizontal/vertical layout) is supported via :func:`marimo.hstack` and :func:`marimo.vstack`.
