Added AI-friendly documentation features to improve interaction with Large Language Models and AI coding assistants:

- Added an ``llms.txt`` file to make HyperSpy more AI-friendly by providing structured information for Large Language Models, following the best practices from the llms.txt specification (https://llmstxt.org). The file uses local RST paths for repository-aware AI assistants.
- Added an online context file (``llms-ctx.txt``) accessible at ``https://hyperspy.org/hyperspy-doc/{version}/llms-ctx.txt`` that converts local RST paths to web URLs for external AI systems. This improves AI-assisted development and support.
- Integrated AI assistance guidance into the User Guide with a simplified workflow using online context files.
