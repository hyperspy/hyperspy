The ``trigger()``, ``connect(kwargs=...)`` for non-default values, ``suppress()``, ``suppress_callback()``, and ``.connected`` methods on ``Event`` are deprecated and will be removed in HyperSpy 3.0. Use ``emit()``, native ``connect()`` with explicit wrapper functions, ``blocked()``, and ``disconnect``/``reconnect`` instead. Currently only ``suppress_callback()`` emits a visible deprecation warning; the other deprecated methods will add warnings once downstream migration is complete.
