``signal.plot()`` is now backend-agnostic: rendering goes through a pluggable
``PlottingBackend`` protocol. Matplotlib remains the default, and an
``anyplotlib`` backend can be selected via the ``Plot.backend`` preference or
the ``%anyplotlib`` IPython magic.

Unlike ``ipympl``, which streams server-rendered images over a Jupyter comm and
needs a live kernel for every interaction, ``anyplotlib`` (paired with the
``anywidget`` GUI) renders in the browser — giving smoother interactivity and
plots that work on frontends lacking ipywidgets support, such as Marimo and
JupyterLite.
