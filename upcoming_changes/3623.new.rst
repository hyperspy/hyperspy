Add a pluggable plotting-backend system: ``signal.plot()``, the interactive
widgets/ROIs and markers now render through a ``PlottingBackend`` protocol.
Matplotlib remains the default; an ``anyplotlib`` backend (install with
``pip install hyperspy[anyplotlib]``) can be selected with
``hs.preferences.Plot.backend = "anyplotlib"`` or the ``%anyplotlib`` IPython
magic. Unlike ``ipympl``, ``anyplotlib`` renders in the browser, so plots stay
interactive without a round trip to the kernel and work on frontends without
ipywidgets support such as Marimo and JupyterLite. Third-party backends can
register through the ``hyperspy.backends`` entry-point group.
