Events now use ``psygnal.SignalGroup`` class-attribute descriptors. Each event-owning class declares its events as ``EventSignal`` attributes on a named ``SignalGroup`` subclass, providing native group-level ``blocked()``, ``connect`` with ``EmissionInfo``, and ``disconnect()``. The ``Event`` class subclasses ``psygnal.SignalInstance`` with a deprecated HyperSpy API shim (``trigger``, ``connect(kwargs=)``, ``suppress``, ``suppress_callback``).
